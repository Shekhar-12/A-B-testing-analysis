# A/B Testing Analysis for Landing Page Conversion

## 📌 Overview
A complete A/B testing project analyzing whether a new landing page improves user conversion rates.

## 📊 Dataset
- Users: 290K+
- Groups: Control (old page) vs Treatment (new page)

## 🛠 Tools Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 🔍 Summary of Steps
- Data cleaning (removing mismatched group–page assignments)
- EDA & visualizations
- Conversion rate analysis
- Hypothesis testing (Z-test)
- Final recommendation

## ✅ Key Insights
- New landing page showed **no statistically significant improvement**.
- Recommendation: **Do not roll out the new page**.

## 📁 Project Files
- `ab_data.csv` — raw dataset
- `Analyze_ab_test_results_notebook.ipynb` — analysis notebook
